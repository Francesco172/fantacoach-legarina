# Guida rapida - FantaCoach sul telefono

## Obiettivo

Arrivare a questo risultato:

**icona FantaCoach sulla Home -> tocchi -> si apre l'app -> Aggiorna dati live -> Genera formazione.**

## Cosa devi fare una sola volta

1. Mettere questa cartella su GitHub.
2. Collegare il repository a Render.
3. Copiare il link HTTPS generato da Render.
4. Aprire quel link dal telefono.
5. Installare FantaCoach dalla funzione del browser.

Dopo questo, non devi più avviare `server.py` dal computer: il backend resta online.

## iPhone

Safari -> link FantaCoach -> Condividi -> Aggiungi alla schermata Home -> Apri come app -> Aggiungi.

## Android

Chrome -> link FantaCoach -> menu ⋮ -> Installa app -> Installa.

## Aggiornamenti futuri

Quando modifichi il codice e aggiorni il repository, il servizio può essere ridistribuito e il telefono riceverà automaticamente la nuova interfaccia al successivo caricamento.
